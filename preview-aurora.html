About

Engineer working at the intersection of AI, networks, and security. The road here started in 2004 with authentication systems and algorithm design, ran through enterprise security infrastructure, 24/7 e‑channel monitoring of a national banking network of 20,000+ ATMs, cryptography for banking‑grade web applications, and nationwide VSAT, terrestrial, and cellular network operations.

Today that experience feeds into deep learning and agentic AI — building and training neural networks with PyTorch, designing autonomous agents capable of multi‑step reasoning, tool use, and self‑correction, and shipping AI‑powered desktop tools, simulators, research, and handbooks. M.Eng in Network Security (Universitas Indonesia) · B.Eng in Informatics (Universitas Gadjah Mada). Every commit lands on GitHub for you to fork & remix.

📚 RAG SOP Assistant

AI-powered Q&A system that transforms corporate Standard Operating Procedure (SOP) documents into a dynamic, conversational knowledge base using Retrieval-Augmented Generation (RAG). Employees ask natural language questions and receive accurate, source-attributed answers grounded in official SOP documents. Features intelligent sentence-boundary-aware text chunking (~500 chars with 100 overlap), 384-dimensional multilingual semantic embeddings via E5-Small, ChromaDB vector storage with cosine similarity search (Top-5 retrieval), and DeepSeek-V3 for context-grounded answer generation.
